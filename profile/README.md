## Game engine integrations

Start with an official plugin and its primary example, or explore a game built with Arcweave.

| Engine | Plugin | Primary example | Game example |
| --- | --- | --- | --- |
| Unity | [Unity plugin](https://github.com/arcweave/arcweave-unity-plugin) | [Unity example](https://github.com/arcweave/arcweave-unity-example) | [Interactive fiction](https://github.com/arcweave/unity-visual-novel-example) |
| Unreal Engine | [Unreal plugin](https://github.com/arcweave/arcweave-unreal-plugin) | [Unreal example](https://github.com/arcweave/arcweave-unreal-example) | [Quest (Windows)](https://github.com/arcweave/arcweave-unreal-quest-example) |
| Godot | [Godot plugin (.NET)](https://github.com/arcweave/arcweave-godot-plugin) | [Godot example (.NET)](https://github.com/arcweave/arcweave-godot-example) | [Adventure (Godot 3.5)](https://github.com/arcweave/arcweave-godot-adventure-example) |

Each repository includes setup instructions and engine requirements.

All three official game engine plugins are open source and MIT licensed. Contributions are welcome, from bug reports and documentation improvements to new features. Open an issue or submit a pull request in the relevant repository.

## What is Arcweave?

Arcweave is a browser-based tool for collaborative narrative design. Build branching dialogue, quests, and story logic on a visual canvas, work with your team in real time, and playtest your stories in the browser. When you're ready, bring your narrative into a game engine with an official plugin, or use JSON exports and the REST API to build your own integration.
